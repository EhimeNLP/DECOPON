# DECOPON

## 概要

DECOPON (Distribution of Emotion from Reader Comments Posted on Japanese News Articles) は、日本語ニュースサイトに掲載された記事に対する読者集団の感情分布を収録したデータセットです。
記事に投稿されたコメントの投稿者の感情の強度とと感情極性を付与することで、感情分布を表現しています。

## ファイルについて

記事1件に対して投稿された30件のコメントを収集し、以下をアノテーションしています。

### Plutchikの基本8感情と感情強度

人間の基本的な8感情（喜び・悲しみ・期待・驚き・怒り・嫌悪・恐れ・信頼）について、各感情がコメントにどの程度表れているかを4段階でアノテーションしています。

| 数値 | 感情強度    |
| -- | ------- |
| 0  | 全く表れない  |
| 1  | 弱く表れる   |
| 2  | 中程度に表れる |
| 3  | 強く表れる   |

### 感情極性

ポジティブ・ネガティブの度合いを5段階でアノテーションしています。

| 数値 | 感情極性    |
| -- | ------- |
| -2 | 強いネガティブ |
| -1 | ネガティブ   |
| 0  | ニュートラル  |
| 1  | ポジティブ   |
| 2  | 強いポジティブ |

30件のコメントを集約し、以下のように感情の分布を表現しています。

```json
{
  "articles": [
{"記事番号":935,
"カテゴリ":"科学",
"記事URL":"https://news.yahoo.co.jp/articles/289b4945b86d4a1c7993066dd3a8ae3152238e8c",
"喜び":[1.0,0.0,0.0,0.0],
"悲しみ":[0.9,0.1,0.0,0.0],
"期待":[0.766667,0.233333,0.0,0.0],
"驚き":[0.833333,0.133333,0.033333,0.0],
"怒り":[0.933333,0.0,0.066667,0.0],
"嫌悪":[0.766667,0.166667,0.066667,0.0],
"恐れ":[0.7,0.266667,0.033333,0.0],
"信頼":[1.0,0.0,0.0,0.0],
"感情極性":[0.033333,0.433333,0.233333,0.3,0.0]},
  ]
}
```

* `記事番号`：記事の識別番号
* `カテゴリ`：記事のカテゴリ
* `記事URL`：ニュース記事の掲載源
* `喜び/悲しみ/期待/驚き/怒り/嫌悪/恐れ/信頼`：`[感情強度0の割合, 感情強度1の割合, 感情強度2の割合, 感情強度3の割合]`
* `感情極性`：`[強いネガティブの割合, ネガティブの割合, ニュートラルの割合, ポジティブの割合, 強いポジティブの割合]`
