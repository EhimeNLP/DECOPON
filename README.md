# DECOPON

DECOPON (**D**istribution of **E**motion from Reader **CO**mments **P**osted on Japanese **O**nline **N**ews) は、日本語ニュースサイトに掲載された記事に対する読者集団の感情分布を収録したデータセットです。
記事に投稿されたコメントに投稿者の感情の強度と感情極性をラベル付けすることで、感情分布を表現しています。

[Yahoo!ニュース](https://news.yahoo.co.jp)の7つのカテゴリ（国内、国際、経済、エンタメ、スポーツ、地域、科学）を対象に、計1,000件（国内:150件, 国際:150件,経済:150件, エンタメ:150件, スポーツ:150件, 地域:150件, 科学:100件）の記事を収集しています。
各記事について30件のコメントを収集し、以下の項目をラベル付けしています。

#### Plutchikの基本8感情と感情強度

Plutchikの基本8感情（喜び・悲しみ・期待・驚き・怒り・嫌悪・恐れ・信頼）について、各感情がコメントにどの程度表れているかを4段階（0:無, 1:弱, 2:中, 3:強）でラベル付けしています。

#### 感情極性

ポジティブおよびネガティブの度合いを5段階（-2:強いネガティブ, -1:ネガティブ, 0:ニュートラル, 1:ポジティブ, 2:強いポジティブ）でラベル付けしています。
<br>



## ファイルについて

各記事について、コメント投稿者の感情の強度と感情極性がラベル付けされた30件のコメントを集約し、以下のような感情分布を作成しました。

```json
{
  "articles": [
    {
      "article_id": 937,
      "category": "科学",
      "article_url": "https://news.yahoo.co.jp/expert/articles/2973377a36b88a09b61ff12c12012278c78e6741",
      "joy": [0.966667, 0.033333, 0.0, 0.0],
      "sadness": [0.833333, 0.1, 0.066667, 0.0],
      "anticipation": [0.8, 0.1, 0.1, 0.0],
      "surprise": [0.933333, 0.066667, 0.0, 0.0],
      "anger": [0.9, 0.066667, 0.033333, 0.0],
      "disgust": [0.766667, 0.1, 0.1, 0.033333],
      "fear": [0.366667, 0.333333, 0.233333, 0.066667],
      "trust": [1.0, 0.0, 0.0, 0.0],
      "polarity": [0.133333, 0.566667, 0.233333, 0.033333, 0.033333]
    }
  ]
}
```

* `article_id`：ニュース記事の識別番号
* `category`：ニュース記事のカテゴリ
* `article_url`：ニュース記事の掲載源
* 各感情(`joy`, `sadness`, `anticipation`, `surprise`, `anger`, `disgust`, `fear`, `trust`)：`［感情強度0の割合, 感情強度1の割合, 感情強度2の割合, 感情強度3の割合］`
* `polarity`：`[強いネガティブの割合, ネガティブの割合, ニュートラルの割合, ポジティブの割合, 強いポジティブの割合]`

## 注意事項
・記事内容は記事URLから取得してください<br>
・記事内容を取得する際は、Yahoo!ニュースの規約に則ってください<br>
