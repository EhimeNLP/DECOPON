# DECOPON

## 概要

DECOPON（Distribution of Emotion from Reader COmments Posted on Japanese Online News Articles）は、Yahoo!ニュースの記事と読者コメントから構築した日本語ニュース感情分析データセットです。各記事の読者コメント30件に付与したPlutchikの基本8感情の強度と感情極性を集約し、記事単位の分布として収録しています。

ニュース記事に対する読者集団の多様な感情反応を分布として分析・予測する研究に利用できます。

## データ件数

| データ | 件数 |
| --- | ---: |
| ニュース記事 | 1,000 |
| 読者コメント | 30,000 |
| 1記事あたりの読者コメント | 30 |

### カテゴリ別の記事数

| カテゴリ | 記事件数 |
| --- | ---: |
| 地域 | 150 |
| エンタメ | 150 |
| スポーツ | 150 |
| 国際 | 150 |
| 国内 | 150 |
| 経済 | 150 |
| 科学 | 100 |
| 合計 | 1,000 |
