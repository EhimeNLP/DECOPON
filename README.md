# DECOPON

## 概要

本データセットは、日本語のオンラインニュース記事に対して、読者コメントから構築した感情分布を付与したものです。

各ニュース記事に対して、記事ID、カテゴリ、記事URLに加え、読者コメント30件に基づく8感情（喜び、悲しみ、期待、驚き、怒り、嫌悪、恐れ、信頼）の強度分布と感情極性の分布を収録しています。感情強度は「0：ほとんど感じない」「1：少し感じる」「2：感じる」「3：強く感じる」の4段階、感情極性は「-2：強いネガティブ」「-1：ネガティブ」「0：中立」「1：ポジティブ」「2：強いポジティブ」の5段階です。

ニュース記事に対する読者集団の多様な感情反応を、単一のラベルではなく分布として分析・予測する研究に利用できます。

## 元データ

- Yahoo!ニュースの記事
- 各記事に投稿された読者コメント

## データ件数

| データ | 件数 |
| --- | ---: |
| ニュース記事 | 1,000 |
| 読者コメント | 30,000 |
| 1記事あたりの読者コメント | 30 |

### カテゴリ別の記事数

| カテゴリ | 記事件数 |
| --- | ---: |
| 地域 | 150 |

| スポーツ | 150 |
| 国際 | 150 |
| 国内 | 150 |
| 経済 | 150 |

| 合計 | 1,000 |

  "article_url": "https://example.com/article/0001",

    "悲しみ": {"0": 0.700, "1": 0.167, "2": 0.100, "3": 0.033},
    "期待": {"0": 0.567, "1": 0.233, "2": 0.167, "3": 0.033},
    "驚き": {"0": 0.800, "1": 0.133, "2": 0.067, "3": 0.000},
    "怒り": {"0": 0.500, "1": 0.267, "2": 0.167, "3": 0.066},
    "嫌悪": {"0": 0.467, "1": 0.300, "2": 0.167, "3": 0.066},
